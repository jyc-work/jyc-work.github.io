## 核心组件

**Agent Loop** 负责执行决策循环；**工具注册表** 管理能力接口；**策略引擎** 处理授权和副作用级别；**状态存储** 保障长任务恢复；**事件系统** 用于审计与重放。

## 执行前

- 是否存在最大轮数、超时、成本预算和取消通道？
- 工具名称和参数是否通过程序校验？
- 写操作是否执行独立的服务端授权？
- 有风险的操作是否要求人工确认？

## 执行中

- 是否为每个运行、步骤、工具调用生成稳定标识？
- 错误和重试是否记录完整的原因与结果？
- 是否能在长任务中找到当前 checkpoint？
- 是否能防止重复执行外部非幂等操作？

## 执行后

- 结果能否通过单元测试、外部 API 回执或状态断言验证？
- 是否可关联输入、工具事件、产物、终止原因？
- 失败是否能给出有用错误，而不是假装任务成功？

## 最小实验

建立一个可控模拟工具，注入成功、超时、拒绝、重复请求、取消和保存失败，写出可运行的回归测试。**这是一张待执行的验收单，而不是测试已通过的声明。**
